# Yatrik UI + features (Voyage Flux format)

Each `DESIGN0N.md` file uses the **same token YAML** and the same section order:

Brand & Style → Colors → Typography → Layout & Spacing → Elevation & Depth → Shapes → Components → **Features**

| File | Screens | UI + features spec |
| --- | --- | --- |
| [DESIGN01.md](./DESIGN01.md) | Landing | Marketing home, signup/login entry |
| [DESIGN02.md](./DESIGN02.md) | Auth | Login, signup, JWT session |
| [DESIGN03.md](./DESIGN03.md) | App Shell + Dashboard | Nav, next trip, weather, checklist |
| [DESIGN04.md](./DESIGN04.md) | My Trips + Destinations | Trip gallery, city pick → create |
| [DESIGN05.md](./DESIGN05.md) | Create Trip + Itinerary | Postgres trips, stops, activities |
| [DESIGN06.md](./DESIGN06.md) | Budget + Passport | Cost rollup, export JSON |

Shorter wireframes (ASCII layouts) remain in `LANDING.md`, `AUTH.md`, and the other page files.
